Collects inventory objects from a VMware vCenter (or standalone ESXi) endpoint on an interval, emitting each object as a JSON message.

Introduced in version 1.20.0.

This input connects to the vSphere API and periodically retrieves the
configured inventory object types, emitting one message per object. It is
useful for feeding CMDBs, asset inventories and monitoring pipelines with
virtual machine, host and datastore state:

```yaml
input:
  vcenter:
    url: https://vcenter.example.com/sdk
    username: administrator@vsphere.local
    password: "${VSPHERE_PASSWORD}"
    object_types: [ virtual_machine, host_system, datastore ]
    interval: 5m
```

By default a sensible set of properties is collected per object type (such as
`name` and `summary`). The `properties` field overrides this
with an explicit list of property paths applied to all configured object
types.

Set `interval` to `0s` to collect exactly once and then shut the
input down, which is useful for batch-style jobs.

### Metadata

This input adds the following metadata fields to each message:

```text
- vcenter_object_type
- vcenter_moref
- vcenter_name
```

## Fields

### `url`

The URL of the vCenter or ESXi SDK endpoint.


Type: `string`  

```yml
# Examples

url: https://vcenter.example.com/sdk
```

### `username`

The username to authenticate with.


Type: `string`  
Default: `""`  

```yml
# Examples

username: administrator@vsphere.local
```

### `password`

The password to authenticate with.
:::warning Secret
This field contains sensitive information that usually shouldn't be added to a config directly, read our [secrets page for more info](/docs/configuration/secrets).
:::


Type: `string`  
Default: `""`  

### `insecure_skip_verify`

Skip TLS certificate verification. Not recommended for production.


Type: `bool`  
Default: `false`  

### `object_types`

The inventory object types to collect. Valid values are `[cluster datacenter datastore host_system network resource_pool virtual_machine]`.


Type: `array`  
Default: `["virtual_machine"]`  

```yml
# Examples

object_types:
  - virtual_machine
  - host_system
  - datastore
```

### `properties`

An explicit list of property paths to collect for all configured object types, overriding the per-type defaults. The `name` property is always included.


Type: `array`  
Default: `[]`  

```yml
# Examples

properties:
  - name
  - summary.runtime.powerState
  - guest.ipAddress
```

### `datacenter`

An optional datacenter name to restrict collection to. When empty all datacenters are collected.


Type: `string`  
Default: `""`  

### `interval`

The time between collections. Set to `0s` to collect exactly once and then shut down.


Type: `string`  
Default: `"5m"`
